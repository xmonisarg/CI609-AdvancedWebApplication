# CI609-AdvancedWebApplication
CI609-AdvancedWebApplication

This assignment, I will be researching, desiging, developling and deploy an advanced web application based on a Mental Health Application.
The app will be anonymous, secure, mobile-friendly, and includes user functions to log data into the app.

The app will be using an API Key to fetch Weather for the user to view when they are going to insert their mood for the day.

The app will be encrypted and stored on locale storage and users can access their past mood logs with a PIN number that is for the user only.
